Why PExL?

  
Excel has 500+ functions and a syntax that punishes anyone who didn't memorize it.
     PExL gives you ~35 readable verbs that compile straight to the formulas you already trust.

How it works

  
A classic compiler pipeline with no Excel dependency in the core — so the whole
     language is unit-tested in isolation against golden PExL → formula cases.

It ships as an offline Excel add-in (built on Excel-DNA) with a built-in
     Monaco editor, so it works inside locked-down corporate environments where modern web add-ins are blocked.
     PExL only writes standard formulas — recipients never need the add-in, and there's zero recalculation cost.
